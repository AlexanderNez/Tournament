// HOW SCORING WORKS

All stats live in one Google Sheet.

There's no separate login here — whoever has editor access to the tournament Google Sheet can update scores and bounty stats. The public board re-reads the sheet automatically, so anything you save there shows up for everyone within about 30 seconds.

Cheat sheet: which tab does what

Teams tab

Columns: TeamID, TeamName, Player1, Player2, Discord1, Discord2. Edit rosters here — add a sub, fix a typo'd tag, whatever. TeamID (team1, team2…) should never change once the tournament starts, since Game and Bounty tabs reference it.

Game1 / Game2 / Game3 tabs

Columns: TeamID, TeamName, Placement, Eliminations. After each game, fill in every team's finishing place (1–20) and elimination count. Points are calculated automatically by the site — you never type points directly.

Bounties tab

Columns: TeamID, TeamName, Headshots, Accuracy, HostElims, Assists, ClipLink, ClipWinner. For the four stat bounties, type each duo's combined total across all 3 games — the site shows whoever has the highest number as the leader. For the clip bounty, paste each duo's clip link into ClipLink, and once staff pick a winner, type YES in that team's ClipWinner cell (leave everyone else's blank).
